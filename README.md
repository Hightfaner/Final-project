# Final Project

## 环境配置

- 操作系统：Windows 10/11
- Python：3.12
- 命令行：PowerShell
- 依赖文件：`requirements.txt`

## 初始化环境

```powershell
cd 'D:\zjj_final project'
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
```

## 环境检查

```powershell
python --version
python -m pip check
```

本地虚拟环境 `.venv` 不需要提交到 Git 仓库。
